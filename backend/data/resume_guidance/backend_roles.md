# ATS Resume Guidance — Backend & Software Engineering Roles

## Target Roles
Backend Engineer, Software Engineer, API Engineer, Platform Engineer, Site Reliability Engineer (SRE), Systems Engineer.

## High-Priority Keywords
REST API, FastAPI, Django, Flask, Node.js, microservices, gRPC, GraphQL,
PostgreSQL, MySQL, MongoDB, Redis, Kafka, RabbitMQ,
Docker, Kubernetes, CI/CD, GitHub Actions, Jenkins,
Python, Go, Java, TypeScript, SQL,
system design, scalability, load balancing, caching, distributed systems,
unit testing, integration testing, pytest, code review, Agile, Scrum.

## Strong Bullet Patterns for Backend

### API Design
- "Architected and deployed RESTful microservices using [framework], supporting [N] daily requests with [X]ms median latency."
- "Designed versioned REST APIs with OpenAPI/Swagger documentation, reducing integration time for partner teams by [X]%."

### Database & Optimisation
- "Optimised [N] critical PostgreSQL queries using indexed views and query plan analysis, reducing p95 response time from [X]ms to [Y]ms."
- "Implemented Redis caching layer for [endpoint/service], cutting database read load by [X]% and improving throughput by [Y]%."

### CI/CD & DevOps
- "Engineered automated CI/CD pipelines using GitHub Actions and Docker, reducing release cycle time from [X] days to [Y] hours."
- "Containerised [N] services with Docker Compose and deployed to Kubernetes, eliminating environment drift across dev/staging/prod."

### System Design
- "Designed event-driven architecture using Kafka for [use case], decoupling [N] downstream services and improving fault tolerance."
- "Refactored monolithic codebase into [N] domain-bounded microservices, improving deploy frequency by [X]% and reducing MTTR."

### Testing & Quality
- "Established comprehensive test suite (unit + integration) with pytest, raising coverage from [X]% to [Y]% and catching [N] regressions pre-release."
- "Implemented automated contract testing between [N] services, preventing [X] production incidents per quarter."

## Evidence Rules (Anti-Hallucination)
- Only include tools, frameworks, and metrics that appear in the candidate's original text.
- If a metric is absent, insert: [X%], [N requests/day], [~Y ms].
- Never add cloud certifications (AWS, GCP, Azure) unless the candidate mentioned them.
