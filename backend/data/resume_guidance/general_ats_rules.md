# ATS Resume Guidance — General Rules

## ATS Fundamentals
- Use a single-column layout with standard section headings.
- Avoid tables, text boxes, headers/footers, or graphics — ATS parsers skip them.
- Use standard fonts: Arial, Calibri, Helvetica, Times New Roman.
- Save as .pdf (ATS-compatible) or .docx; never .pages or .odt.

## Keyword Matching
- Mirror exact keywords from the job description (JD) in your resume.
- Place the most critical JD keywords in your Professional Summary and first experience bullet.
- Use both spelled-out and abbreviated forms: "Continuous Integration (CI)" and "CI/CD".
- Include a dedicated Skills section so ATS can extract skills quickly.

## Bullet Structure — STAR Format
- Every bullet should follow: Action Verb → Task/Situation → Action → Result/Impact.
- Start every bullet with a strong past-tense action verb (Architected, Engineered, Automated, Delivered, Reduced, Improved, Deployed, Designed, Spearheaded).
- Quantify impact wherever possible: percentages, time saved, scale, team size.
- If a metric is not known, use a bracketed placeholder: [X%], [N users], [~3 weeks].
- Keep bullets to 1–2 lines. Remove "I" and filler phrases.

## Weak Opener Replacements
| Weak | Strong |
|------|--------|
| Responsible for… | Owned / Managed / Led… |
| Worked on… | Engineered / Developed / Built… |
| Helped with… | Collaborated to deliver / Contributed to… |
| Did… | Executed / Implemented / Shipped… |
| Used X to… | Leveraged X to deliver… |
| Participated in… | Contributed key modules to… |

## Professional Summary Rules
- 3–4 sentences maximum.
- Sentence 1: Title + years of experience + top 2 domains.
- Sentence 2: Key technical strength or specialisation.
- Sentence 3: Impact statement (what you delivered, not just what you know).
- Sentence 4 (optional): Soft-skill differentiator or career goal.
- Never use "I" in the summary.

## Section Order (ATS Preferred)
1. Name + Contact (email, phone, LinkedIn, GitHub)
2. Professional Summary
3. Technical Skills
4. Work Experience (reverse chronological)
5. Projects
6. Education
7. Certifications (if any)
