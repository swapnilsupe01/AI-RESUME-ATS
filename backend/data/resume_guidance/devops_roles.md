# ATS Resume Guidance — DevOps, Cloud & SRE Roles

## Target Roles
DevOps Engineer, Cloud Engineer, Platform Engineer, Site Reliability Engineer (SRE), Infrastructure Engineer, MLOps Engineer.

## High-Priority Keywords
Kubernetes (K8s), Docker, Helm, Terraform, Ansible, Pulumi,
AWS (EC2, S3, EKS, Lambda, RDS), GCP (GKE, Cloud Run), Azure (AKS),
CI/CD, GitHub Actions, GitLab CI, Jenkins, ArgoCD, FluxCD,
Prometheus, Grafana, Datadog, ELK Stack, OpenTelemetry,
Linux, Bash, Python, Go,
IaC (Infrastructure as Code), GitOps, service mesh, Istio, Envoy,
SLO, SLA, SLI, MTTR, MTTF, incident response, on-call, runbooks,
security scanning, SAST, container hardening.

## Strong Bullet Patterns for DevOps/SRE

### Infrastructure & IaC
- "Provisioned and managed cloud infrastructure for [N] services using Terraform on [AWS/GCP/Azure], reducing manual setup time by [X]%."
- "Authored Helm charts and Kubernetes manifests for [N] microservices, standardising deployment across dev/staging/prod environments."

### CI/CD Pipelines
- "Designed and maintained CI/CD pipelines using [tool], reducing average deployment time from [X] minutes to [Y] minutes."
- "Implemented GitOps workflow with ArgoCD, enabling automatic rollbacks and cutting deployment failures by [X]%."

### Observability & Reliability
- "Instrumented [N] services with Prometheus + Grafana dashboards, reducing MTTR from [X] hours to [Y] minutes."
- "Established SLO/SLI framework for [N] critical services, maintaining [X]% uptime and reducing P1 incidents by [Y]%."
- "Implemented distributed tracing using OpenTelemetry, reducing time-to-diagnose production issues by [X]%."

### Container & Orchestration
- "Migrated [N] monolithic services to containerised microservices on Kubernetes (EKS/GKE), improving resource utilisation by [X]%."
- "Configured horizontal pod autoscaling and node auto-provisioning, handling [X]x traffic spikes with zero downtime."

### Security & Compliance
- "Integrated SAST/DAST tooling into CI pipeline, reducing security vulnerabilities reaching production by [X]%."
- "Hardened container base images and implemented network policies, achieving compliance with [standard] requirements."

## Evidence Rules (Anti-Hallucination)
- Only claim cloud certifications (AWS, GCP, Azure Certified) if the candidate's resume explicitly mentions them.
- Only mention specific tools (Terraform, ArgoCD, Istio) if they appear in the original text.
- Use [X%], [N services], [~Y hrs] for any missing metrics.
