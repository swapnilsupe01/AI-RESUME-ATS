# ATS Resume Guidance — Data Science, ML & AI Roles

## Target Roles
Data Scientist, Machine Learning Engineer, AI Engineer, MLOps Engineer,
Data Engineer, NLP Engineer, Computer Vision Engineer, Research Engineer.

## High-Priority Keywords
Python, PyTorch, TensorFlow, scikit-learn, XGBoost, LightGBM, Keras,
Pandas, NumPy, Spark, Dask, Airflow, dbt,
SQL, PostgreSQL, BigQuery, Snowflake, Redshift,
Hugging Face Transformers, LLM, RAG, embeddings, vector database,
FAISS, ChromaDB, Pinecone, LangChain,
MLflow, Weights & Biases (W&B), DVC, model registry,
Docker, Kubernetes, REST API, model serving, TorchServe, FastAPI,
A/B testing, feature engineering, hyperparameter tuning, cross-validation,
precision, recall, F1, AUC-ROC, RMSE, MAE, accuracy.

## Strong Bullet Patterns for Data / ML

### Model Development
- "Trained and fine-tuned [model type] on [N] samples, achieving [X]% [metric] on held-out test set, outperforming baseline by [Y]%."
- "Designed and implemented [algorithm] pipeline for [task], reducing inference latency by [X]ms at [N] requests/second throughput."

### Data Engineering
- "Built end-to-end data pipeline ingesting [N] records/day from [source] using [tool], reducing data freshness lag from [X] hours to [Y] minutes."
- "Engineered feature store for [N] ML models, centralising [N] features and cutting feature development time by [X]%."

### Model Evaluation & Experiment Tracking
- "Managed [N] experiment runs using MLflow/W&B, reducing model selection time by [X]% through automated metric tracking."
- "Implemented cross-validation framework for [N] models, improving generalisation and reducing overfitting rate by [X]%."

### NLP & LLM
- "Fine-tuned [model] on domain-specific corpus of [N] samples, improving task accuracy from [X]% to [Y]%."
- "Built RAG pipeline using [embedding model] + [vector DB], reducing hallucination rate by [X]% compared to base LLM."
- "Designed prompt engineering framework for [N] task types, improving output quality score by [X]% in human evaluation."

### Deployment & MLOps
- "Deployed [N] ML models to production via FastAPI + Docker, serving [N] predictions/day with [X]ms p95 latency."
- "Automated model retraining pipeline with Airflow, reducing manual intervention by [X]% and maintaining performance within [Y]% of baseline."

## Evidence Rules (Anti-Hallucination)
- Only mention specific models (GPT-4, Llama-2, BERT) if the candidate's original text names them.
- Only claim dataset sizes, accuracy numbers, or benchmark results present in the original.
- Use [X%], [N samples], [~Y ms] for missing quantification.
- Never claim publications, patents, or competition rankings not in original.
